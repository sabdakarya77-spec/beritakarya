✍️ Mode WordPress

Editor seamless satu kontainer contentEditable — mirip WordPress klasik. Cocok untuk penulisan cepat dan panjang.

WordPressEditor.tsx Satu div contentEditable merender SEMUA blok teks sebagai HTML kontinu.
contentEditable data-block-id
🎯 Fitur:
  • Enter =

    baru (tanpa split block)

  • Backspace normal (tanpa merge block)
  • Inline toolbar (bold, italic, dll)
  • Formatting via document.execCommand
  • Blok non-teks (gambar, embed) di-render terpisah di bawah
Komponen pendukung:
  • EditorialToolbar — toolbar format, alignment, color
  • InlineToolbar — toolbar inline (bold/italic)
  • Sync: onInput → syncToBlocks() → updateBlock()

🧱 Mode GridBlock

Setiap blok adalah unit terpisah. Bisa di- drag, edit, ganti tipe, dan punya kontrol sendiri. Cocok untuk layout kompleks.

BlockList.tsx Loop blocks[] → render BlockWrapper → BlockRenderer
🎯 Fitur:
  • Setiap blok punya kontrol: naik, turun, hapus, tambah
  • Split/merge block (Enter/Backspace)
  • AddBlockMenu — tambah blok di antara blok
  • Focus mode — sembunyikan kontrol
  • Drag & Reorder (coming soon)
Komponen pendukung:
  • BlockWrapper — wrapper dengan kontrol + border aktif
  • BlockRenderer → BlockRegistry → masing-masing block
  • ParagraphBlock, HeadingBlock, QuoteBlock, ImageBlock …
  • InlineToolbar, SlashCommand, AddBlockMenu
